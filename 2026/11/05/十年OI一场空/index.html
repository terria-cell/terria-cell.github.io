十年OI一场空

发表于 2026-11-05

十年OI一场空

关于我

如各位所见，我是一个OIer——奖没得过一个，浪费三年青春的那种。所以这篇文章也绝不是信竞大佬退役书——毕竟我既没有发在洛谷上，也没有在比赛里写行 AFO, FUCKCCF 的注释。不过是想了许久，写了一点点杂乱的东西

入门

我小学的时候学了很多杂七杂八的东西。其中包含 Python Coding等等等等······总之那个时候能写出来几个小软件demo，看了两遍杂七杂八的教材的我自以为自己很有天赋，于是参加了学校竞赛队的选拔。现在想来，那简直是一个佳豪。
那个时候这个梗都还不存在呢。
当时我可是一行 C++ 不会，我也不知道怎么着就进了一个入门班级。我们的老师带着我们敲

从那个时候起，我的码风就是这样紧凑得难看。这也是我人生中第一次忘写 return 0 了。

后来我们交了几个简单算法——几个排序、递归递推、DFS和BFS搜索、贪心。就这样，我通过了考试，正式进入了比赛队伍。

现在回忆起来，那场考试，我有一道题是硬生生打表做出来的。现在那个时段其他的都忘了，独独记得那道题。

学习

我进入队伍的前两个月正好学图论和dp。从哪里开始，我就一直似懂非懂地跟着，老是自以为懂了。

做我左边的家伙很geek，但是偏偏不是打OI的，他来这里只是为了有个电脑。他退出极域，同时过原神、崩铁、崩坏的剧情。这似乎是我当时为数不多玩过的二游。他还从GitHub上下了个原神自动钓鱼程序。我记得有一次课件。没玩过这个游戏的我指挥他把角色挤到一个角落，切换角色，把自己卡出了地图。我们在混乱的建筑碎片——这些大多数是那种建模软件地形刷子刷出来的笔画的末端，被遮盖住就没有删掉模型。还有一些是剧情地图，被放在地底。我们小心控制角色体力和血量，慢慢下降，直到周围环境光变成温馨的橙色——我们把降落到了一小块完整的地图，有湖泊和中国风的仙鹤。后来我才好像知道，那是一段下个版本的未完工地图。是谁告诉我的，不记得了。

这哥们后来很早就退了。

坐我右边的家伙是个课内天才。他长得小小的、面容小小的，真的就是一个小孩子。但是他学习很厉害——从课内学业到文学积累。他喜欢上课摸鱼玩喵喵竞赛和编程猫社区的一些3D游戏。他还偶尔教导我代码。他也是来玩的。

后来他中考的时候跨区考上了人大附，大概是不再竞赛了。

做我正对面的哥们，是一个很不错的家伙，认真听课。他会剪辑，会调音，B站上有播放量破千的视频。这个是我最喜欢的他的鬼畜视频那一天，国王想起了他年仅3岁时的毫无畏惧 ，视频里的配乐还是我们在一节晚自习上拿MP3偷偷听的。

他是个很棒的家伙，经常教我代码。他考走了。

做我对面的对面，我正好能窥屏的，一个人是个数学偏科怪才。他家里严，所以来这里玩玩网页小游戏和数独。后来他高考英语提了好多分，考走了，某个学而思的尸块还拿他的案例来宣传。另一个是为数不多我们那届上了高中现在还在打的。他很厉害，乍一看很呆呆的一个人，却很棒。他经常在我们的Minecraft服务器上和我PVP，盾斧很好。今年大概也就是他的AFO之年了。

后来，学着学着，我们的“起手式”成了

很难看但是很标准的竞赛式。我也早就把 Python 扔掉了。当然，我本身也不是很想要拿一个奖，摸摸鱼，得过且过地，我自然学得很烂。

一次我们做USAOI的题，他们集思广益出算法，我能做的居然只有一句一句翻译——我是英语最好的。毕竟是个布鲁克莱恩人嘛。但是我再就什么都做不了了。我把题目输给kimi——那时候AI编程远远没有兴起，Deepseek R1都没出现，kimi自然写不出什么。最后一个比我大一级的哥们一个 swap() 秒了，我在那里空悲切。

我记得有一次考试，我连第一问，一道绿题，都没切出来，靠着提前藏在U盘里的线段树版子蒙混过关。老师下课告诉我们那个巨想学算法的女生说：

我不建议你学校去了

又拉住我

要认真，好好学——你要理清自己到底想要什么

我们的老师是个校内老师，也是女的——所以这话不是性别歧视她。她哭着退了。

一年后，理清了自己想要什么的我也退了。

比赛

我的水平，顶天了也就是自己切个绿，努努力切个熟悉的蓝，能稳拿的只有黄和红了。我们那时候洛谷连青色都尚未发明呢。我这辈子只切过一道紫题。

自然，我连初赛都反复卡住，最终也没有获得什么成绩。

大概是因为一开始，我就并不是很在乎这OI吧。

所以退出的时候，我才没有是不是马上就NOIP了、是不是马上省一了的遗憾。我甚至没能挑一场，哪怕是洛谷月赛——因为我从来不喜欢参加这种活动——打出 AFO ，就离开了。

总之，这就是结束了。

告别

总之，我的OI生涯很烂，没有成功，甚至没有努力。与血泪更是无缘。

不过我倒是哭过呢。

但是，这毕竟是我的3年青春。

所以又过去了一年多，我终于写了这篇文章，和那个青春最后一次告别。

接下来会有点点中二。

记得几年前那句 Hello World 吗？

Goodbye World of OI! 再见了我3年的青春！！！

这就是，我的，AFO啦！！！

完！结！撒！花！
